# Live南京屏保

![Live南京屏保](LiveNanjing/Resources/thumbnail.png)

一个播放“Live南京”城市直播画面的 macOS 屏幕保护程序。

[打开 Live南京直播网页](https://m2.nbs.cn/eventlive/280714.html)

屏保启动时会重新读取 Live南京 页面和接口，随机寻找当前可用的直播流。失效的 HLS 清单和无法开始播放的视频会被自动跳过。视频使用铺满裁切方式显示，不会因为画面比例不同而留下黑边。

设置中可以选择：

- 随机选择一个地点并持续直播；
- 每隔 5、10、15 或 30 分钟随机切换直播地点；
- 视频流名称可设为不显示、常显或显示后淡出；
- 视频画面可选择彩色或黑白播放；
- 可在右下角短暂显示南京区县边界和当前直播摄像头的位置，随后自动淡出。

屏保始终静音播放。

## 构建

需要完整安装 Xcode。

```sh
./build.sh arm64
./build.sh x86_64
```

构建产物位于 `build/<架构>/`。GitHub Actions 会分别生成 Apple 芯片和 Intel 版本；推送 `v*` 标签时会同时创建 Release。
